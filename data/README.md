# Data

This directory stores small, derived, or cleaned data required by the application.

- `raw/`: Small raw inputs or samples extracted from larger datasets.
- `interim/`: Intermediate outputs that can be regenerated.
- `processed/`: Cleaned data used directly by model training and route planning.
- `external/`: External road-network exports such as OSMnx/OpenStreetMap data.

Large UrbanEV datasets are currently kept under `ML/Data/`.
